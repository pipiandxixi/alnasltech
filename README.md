# alnasltech.com

Public pages for my apps, published with GitHub Pages at https://alnasltech.com .

**One folder per product** (`diskprune/`, later others). Each product keeps its own pages in its folder:

- `<product>/index.html`: what it is
- `<product>/support/index.html`: support page (the App Store "Support URL")
- `<product>/privacy/index.html`: privacy policy (the App Store "Privacy Policy URL")

Shared style: `assets/site.css`. `CNAME` names the domain, `.nojekyll` turns Jekyll off (the pages are plain HTML).
Adding a product: copy a product folder, change the text, add a card to `index.html`.
Nothing private goes here: this repository is public.
